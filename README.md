# Little Orbit - Space Quiz

Little Orbit is a self-contained, 10-question space exploration quiz. It includes answer feedback, a score and progress indicator, keyboard shortcuts, and a results screen. The app is implemented in one HTML file and needs no server, framework, or external dependencies.

## Run locally

Open `index.html` in a modern web browser. You can also serve the repository with any static file server if you prefer.

During a quiz, press `1` through `4` to select an answer. Press `Enter` to check it, then press `Enter` again to continue.

## Deployment

GitHub Actions publishes `index.html` to GitHub Pages whenever changes are pushed to `main`. A deployment can also be started manually from the Actions tab using **Deploy to GitHub Pages**.
